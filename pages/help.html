Help

Go to the index to see all your golinks.

The index allows you to list, create, edit, and delete your golinks.

There are two easy ways to quickly access the index:

  1. Type go links or go / in your browser's address bar, then press Enter
  2. Pin the extension in your browser's toolbar, then click its icon and select Options

How to configure auto-creation of shared golinks

Entering a golink name that doesn't yet exist can open your shared link creation URL instead of the create page:

  1. On the index, set a Shared CSV URL
  2. Click Add Shared Link Creation (or Configure Shared Link Creation)
  3. Enter a URL template, using {{name}} where the link name goes
  4. Select Open this URL for unknown go links, then click Save

Only {{name}} is filled in. {{url}} is empty and {{hasUrl:...}} is left out.

Using a Google Sheet as a shared CSV

Only the first two columns (name, URL) of the CSV are used. Other columns can hold data like a description or owner.

  1. In Google Sheets, select File > Share > Publish to web, publish the sheet as CSV, then copy the URL
  2. On the index, set the URL as the Shared CSV URL. If the sheet has a header row, select Ignore the first line (header row)

Adding links with a Google Form

A Google Form with prefilled data can be used as the shared link creation URL:

  1. Create a Google Form with questions titled Name, URL, and Description, and set it to collect email addresses
  2. Select Get pre-filled link, enter placeholder values, then copy the link
  3. In the link, replace the placeholder values with {{name}} and {{url}} (for example, https://docs.google.com/forms/d/e/FORM_ID/viewform?usp=pp_url&entry.111={{name}}{{hasUrl:&entry.222={{url}}}})
  4. Use the result as the URL template for Add Shared Link Creation

To update the sheet when the form is submitted, attach an Apps Script to the form (Extensions > Apps Script), set the sheet ID, then add an On form submit trigger for the function. This sample script adds a row (name, URL, description, submitter's username), sorts the sheet by name, then deletes the form response:

function updateGoLinksSheetOnFormSubmit(e) {
  const answers = {};
  e.response.getItemResponses().forEach(r => {
    answers[r.getItem().getTitle()] = r.getResponse();
  });

  const file = SpreadsheetApp.openById("<Google-Sheet-Id>");
  const sheet = file.getSheetById(0);

  sheet.appendRow([
    answers.Name,
    answers.URL,
    (answers.Description ?? ""),
    e.response.getRespondentEmail().split('@')[0]
  ]);

  sheet.sort(1);

  e.source.deleteResponse(e.response.getId());
}

Tips

The name of a golink will always be lowercase.

If you enter a golink name that doesn't yet exist you'll be forwarded to create a new golink.

You can namespace golinks with slashes (gh/repos).

To search your golinks, type a name after go + Space. Select a suggestion to open it, or press Enter to use the name as typed.
